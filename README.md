## Problem Statement

Recruiters and hiring managers often have little time to check a candidate's skills and past work. Data and AI beginners like me need one clear place to show projects, code, and live demos.

## What I Built

In this project, I built a responsive portfolio website with React and Vite. It has sections for my technical skills and my projects. Each project links to its live demo and GitHub repository. I deployed the site on Vercel.

## Key Features

- Shows a clean, minimal layout that works on different screen sizes.
- Uses clear typography and a modern visual design.
- Lists my technical skills in a dedicated section.
- Presents my projects in a dedicated section.
- Links each project to its live demo and GitHub repository.
- Adds smooth animations and interactive elements.

## How to Run Locally

Clone the repository:

```bash
git clone https://github.com/mathan-ponraj/mathan_portfolio.git
```

Go to the project folder:

```bash
cd mathan_portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```


## What I Learned and Future Improvements

**What I learned**

- Built a React app with Vite and learned how to debug it.
- Learned how to deploy a site on Vercel.
- Before, I wrote code in VS Code and pushed it to GitHub with many Git commands. This often caused Git errors.
- Now, once the site is live, I update it directly on GitHub. Each commit goes live on Vercel in about 2 minutes.
- This setup means fewer typed commands and fewer manual errors.
- I can also check problems in the browser console, fix them, and see the change go live quickly.

**Future improvements**

- I will add more projects to this portfolio as I build them.
