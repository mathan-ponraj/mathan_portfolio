## ✦ Getting Started

Clone the repository:

```bash
git clone https://github.com/mathan-ponraj/mathan_portfolio.git
```

Navigate to the project directory:

```bash
cd mathan_portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## ✦ Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
